# 0.1.19：先确认视频流退役，再关闭视频 TCP

日期：2026-11-17。分支 `mercedes-carlife`，基于0.1.18提交 `7633d2d25663b5f8cbe311c5595e4ad318762fcf`。本轮修复屏幕流退役顺序及其资源所有权，没有新奔驰实车证据。

## 已复现的风险与证据边界

参考DiPlay固定提交 [615b32c](https://github.com/shihabal3amri/DiPlay/tree/615b32ce0b40cd0b99ce94ba23a512001553684f) 的屏幕异常EOF处理：接收端在未正常退役时看到视频连接结束，可以关闭整个CarPlay会话；正常TEARDOWN主动关闭屏幕则不走异常路径。

本项目新增独立编写的双TCP接收端回归：使用真实AirPlayClient、VideoSender和独立视频/控制socket，接收端遇到未声明的视频EOF就关闭其所属控制连接。按0.1.18的stop→TEARDOWN顺序，已观察到控制连接结束及后续请求失败。该测试复现一种明确的兼容风险，不证明奔驰MBUX的故障根因已确定，也不代表运行了完整DiPlay接收端。没有复制或打包DiPlay的GPL源码。

## 改动

1. 永久Home让出主屏时，采用：停止新视频输出但保留TCP → 发送屏幕TEARDOWN → 确认后关闭本地视频socket/释放发送器。音频、CarWith与控制连接继续独立管理。
2. 新增OrderlyScreenRetirement持有待退役发送器。全局输出字段清空后，旧sender/socket仍有明确所有者；拒绝、超时和3次恢复预算耗尽不会丢失它，也不会叠加新流。
3. 语义成功以前保持停发与socket；迟到的RTSP应答不自动提交已超时尝试，之后仍需确认式重试。对端可能已处理超时的请求，因此重试不保证各车机都接受；耗尽后等待用户明确操作或断开。
4. 恢复过程中数据端口已经打开、但RECORD/启动失败时，同样交给退役所有者，避免finally直接stop产生提前EOF。
5. 手动断开先封闭屏幕协调器、保留待退役socket，完成整会话TEARDOWN或既有失败退网处理后，再统一释放活动/待退役发送器。真正结束、控制关闭和连接更替可以立即清理旧资源，阻塞的控制响应不能阻止资源close。
6. 屏幕SETUP、TEARDOWN和恢复RECORD携带预期连接代次；旧任务不能对重连后的同一个AirPlayClient发送新屏幕的退役命令。旧onEnded仍受当前发送器身份保护。

临时倒车借屏仍沿用保留连接、按归属暂停图像和新IDR恢复的策略；此次发现不意味着所有Home/倒车都必须TEARDOWN。0.1.18的邀请入口、资源约束、有限重试、音乐归属和语音流程保留。

## 新诊断

`SCREEN-RETIRE:` 区分 video paused/TCP retained、TEARDOWN unconfirmed、TEARDOWN confirmed和session cleanup。日志只含阶段，不记录媒体正文、配对密钥或语音内容。

回主页发生问题时，优先核对：资源交接 → 停发 → TEARDOWN状态 → 视频socket关闭 → 用户再次进入 → 新SETUP/RECORD/IDR。不能只凭app仍连接或发送FPS=0判定成功/卡死。原车显示期间0FPS可以正常，资源归手机后应恢复实际画面和触摸。

## 本地验证

完整门禁通过：standard1085项、remote bridge24项，均0失败/错误/跳过；Spotless、standard lint（0错误）、standard debug构建及同证书校验通过。相对0.1.18新增10项测试。调试证书SHA256保持 `cf224300d4bde33160f08559301026f393c2916ea8131eaad8adefad0fd7b266`。回归覆盖旧顺序异常EOF、新顺序保留控制、拒绝、超时及迟到应答、取消、重连隔离、手动停止延期清理、预算耗尽和恢复中途失败。协议回环与单元测试不代替GLC实车验收。

## 安装与测试

APK：com.mcarplay.app，0.1.19-debug/versionCode1190000，沿用原调试证书，可覆盖安装。先保留现有蓝牙配对。

1. 先不开语音，播放网易云。奔驰原车主页→点CarPlay返回，连续5次；检查原车按钮、中控触摸、画面及音乐。
2. 分别从CarPlay与原车主页进入倒车再退出，各3次；应恢复到借屏前归属，不能强抢倒车影像。
3. 再点击小爱、长按方向盘语音键各3次，检查实际车载麦克风识别、语音结束及画面恢复。短按原车语音分配不在本轮更改。
4. 最后交叉测试语音/回主页/倒车。若失败，注明具体动作时间和屏幕/声音状态后导出脱敏日志。

本轮没有新增Opus/AAC-ELD输入、GPS/车辆数据/仪表导航或原生歌词，不承诺已解决奔驰语音RTSP400或达到稳定60FPS。0.1.19尚无新实车数据。
