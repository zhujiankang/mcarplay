## 修复

1. 入站/出站共用BluetoothConnectionGate。车机入站在启动iAP2前预留所有权，并关闭仍连接中的出站socket。取消回调在门闸锁外执行，不能堵塞状态查询。
2. 已完成出站连接或现有入站不被重复连接替换；迟到的出站成功不能建立第二会话。旧连接结束不能清除新连接所有权。
3. 每个候选开始、SDP返回和实际连接时重查；目标选择变化后不继续用旧候选连接其他设备。因入站取消的尝试记CANCELLED，不作为车机拒绝证据。
4. 配对状态变化时清除对应服务/配置文件缓存与一次性提示状态，避免删除重配后沿用上一配对的结果。
5. 补握手摘要rxBytes/detect/frames/ready。只记数量与状态，不新增原始报文或配对材料；可以区分无字节、只有DETECT、已有有效同步帧。

没有更换UUID、伪造蓝牙硬件身份、强制断开HFP/A2DP或导入外部协议代码。0.1.20的屏幕、语音、资源仲裁与媒体功能保留。

## 安装与实车测试

1. 覆盖安装，先保留当前配对，选择奔驰为目标；让应用处于连接/公告状态后，在奔驰设备页断开再连接一次手机，观察CarPlay入口是否出现。
2. 先检查BT-ARBITER是否接纳入站，再看LINK-NEGOTIATION及BT_LINK/IAP2_IDENTIFIED，不把蓝牙电话/音乐已连接当成iAP2成功。
3. 若仍无图标且车机保留了旧识别结果，可在新APK已运行并发布公告后，再做一次两端删除配对、重新配对。反复删除不是修复，也不保证清除奔驰内部缓存；普通Android应用无法强制奔驰重新执行服务发现。
4. 图标出现并进入CarPlay后，再测Home/倒车/小爱。若仍失败，记录具体时间并导出本版报告；rxBytes=0与detect>0、frames=0对应不同后续排查。

本轮不能宣称奔驰连接已恢复；需0.1.21新实车证据。也不承诺本轮解决之前语音、低帧率或屏幕恢复问题。
