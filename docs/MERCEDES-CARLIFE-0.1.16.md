## 本版修改

1. 奔驰保留原屏幕连接的特例只用于永久归属仍是手机的临时借屏。倒车BORROW仍按归属门控图像、保留原激活；所有借用归还且允许输出后，从新IDR恢复，不重复屏幕SETUP/RECORD。
2. 主屏永久TAKE时退役视频发送器，仅TEARDOWN当前成功建立的屏幕流，携带type110、uuid和streamConnectionID。CarWith源、音频、控制与iAP2继续；合法requestUI/新邀请后确认主屏申请，以新流ID、密钥和激活周期恢复。保留多借用、约束、旧事件/连接隔离及每激活一次RECORD。
3. 参考固定CarPToCarL1.2.51，网络虚拟iAP2忽略空证书、不将其当作认证成功；对非空证书中的EC公钥OID仅作挑战长度提示，在没有车型固定策略/记忆优先项时32B优先。重复证书不重复启动当前挑战。OID匹配不是证书验证，不改变既有信任或ACK失败规则。
4. iAP2永久无ACK诊断补充session、CSM消息ID、长度、重试次数和lastAck，不输出证书、挑战、歌曲、歌词或文件正文。下次可区分未确认的是认证控制、媒体控制还是文件传输，无需公开原始载荷。

参考仍为CarPToCarL提交 `3cbc8e85544bcffcc2aa45f1f3c5e1c70f9ca715`，MIT归属保留。没有捆绑第三方APK或OEM组件。

## 尚未解决

- 奔驰对speechRecognition/type100/format0x40输入SETUP的RTSP400。0.1.14已有“不拆未创建输入流”保护，本报告证明其生效，但并未解决拒绝。本版不使用手机麦克风冒充车机回传，不能宣称小爱已能识别。
- 语音后CarWith源帧率下降的具体内部原因；该窗口未见明显中继积压。保留0.1.15音频资源/识别门控，仍需实车回归。
- 独立网络iAP2未确认包的根因。本版补输入处理和错误上下文，尚不能证明该车使用EC证书或ACK故障已消除。
- 仪表实际封面渲染、原生歌词、GPS/车辆/仪表导航转发、完整通话与持续60FPS。歌词开关仍只是默认关闭、要求源端提供匹配新鲜歌词的标题替换实验，没有网易云专用歌词接口。

## 覆盖安装与验收

版本0.1.16-debug/1160000，包名com.mcarplay.app，沿用原调试证书，可覆盖安装；先保留现有奔驰蓝牙配对。

1. 先不调用语音，确认画面/触摸和音乐。按奔驰原车主页触摸键，确认主页可操作；再点CarPlay进入，重复3次，记录动作时间与是否恢复。
2. 单独测试倒车临时借屏，确认不抢屏、归还后恢复，与永久主页分开记录。临时借屏不应增加屏幕SETUP/RECORD，永久TAKE返回应仅退役/重建屏幕。
3. 再分别测试方向盘长按和画面内小爱按钮，记录前后FPS、是否识别、触控/音乐能否继续。短按仍由奔驰分配。RTSP400存在时，“弹出小爱”不能记为麦克风成功。
4. 如需系统播放器回退，在系统授予mcarplay通知访问后重新连接；播放网易云并切歌，分别观察中控原生媒体页、仪表的歌名/歌手/封面。通知访问不保证车机订阅或歌词支持。
5. 每轮导出诊断，附动作时刻。检查新ACK错误上下文、实际 `MEDIA-BRIDGE: subscribed`、`artworkSetup`、`artworkSuccess` 及麦克风认证包/回传计数。能力声明列表里的5000/5001不等于真实订阅。
